DayGuessGame:
	> Hi, welcome to the day guess game!
	> The game displays a random date.
	> Currently from AD 1000 to 2500.
	> You're up to calculate the day of the week e.g., Wednesday.
	> The program counts correct guesses and measures time.

OS:
	> The game works on Linux.
	> It works perfectly on standard xfce terminal (100x28), 
		and scales with the terminal's font size.
	> If not try to adjust the window manually.
	> You can also use ctrl button and +/- for bigger font, 
		then adjust the window size manually.

RUN:
	> Open terminal in the game's directory.
	> Type: python3 dgg.py

PLAY:
	> Learn how to calculate the day of the week from any date.
	> Calculate for the randomized date.
	> Type a two letter short of the day:
	> mn =Monday, ty =Tuesday, we =Wednesday, tr =Thursday, 
		fr =Friday, sa =Saturday, sd =Sunday
	> Press ENTER to check, then ENTER to play again.
	> To exit the game type q.

VERSION:
	> Version is playable (3.1).
	> Some additional features are under development.
